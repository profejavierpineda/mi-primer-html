# 🚀 Mi Primer Proyecto Web

¡Bienvenidos a mi primer proyecto web! Esta es una página sencilla creada para practicar las bases del desarrollo web estructurando contenido e integrando estilos modernos.

---

## 📌 Descripción

El proyecto consiste en una página de bienvenida para un **Curso de Programación**. Fue diseñado con una estructura minimalista y centrado en la interfaz para ofrecer una experiencia limpia y visualmente atractiva.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio (`<h1>`, `<p>`).
* **Tailwind CSS / CSS:** Estilos modernos, diseño responsivo y tipografía.

---

## 💻 Visualización del Proyecto

La página incluye:
- Un encabezado principal (`<h1>`): *Bienvenidos*
- Un párrafo descriptivo (`<p>`): *Curso de programación*
- Un diseño centrado en pantalla adaptable a dispositivos móviles.
